# 电路助手 Studio 0.9.1

“电路助手”是一款离线优先的 Windows 电路设计桌面软件雏形。它将可收纳的元件物品栏、交互式构图、需求生成、电路识图、公式解题、电路优化和分层知识库集中在同一个工作空间；可选接入本机视觉/语言模型，在断开外网后继续推理。

## 当前可用功能

- 准确性修复（2026-10-16）：统一 SI 单位与参数角色解析，修复多参数修订、求解目标、LED 电阻功率及 RC/555/运放选值；新增从 BOM 独立复算的审查、高通与反相图纸，以及模型答案覆盖保护。保留原评测标准，回归与新增验证分别统计；详见 [修复与复测报告](docs/ACCURACY-IMPROVEMENTS-2026-10-16.md)，实际生效的提示词见 [工程提示词](docs/ENGINEERING-PROMPTS.md)。

- Agent 工作台：任务输入、实际生成/修订/审查轨迹、模型跳过或失败状态，以及最近 8 次本机运行记录。方案和优化报告按运行保存独立快照，点击旧记录会恢复它自己的结果；异常关闭时未完成任务会明确标为中断，不会自动重放模型请求。0.9.1 变更和证据见 [发布说明](docs/RELEASE-0.9.1.md)。

- 智能体评测与训练（0.9.1）：54 例 × 6 维度 × 5 级难度的高难度评测集（`evaluation/circuit-eval-v1.json`）+ 评分器（`npm run eval:agent`），覆盖生成/修订/求解/检索/安全门禁/工程审查；训练把通过率从 53.7% 提升到 100%，求解器新增混联、带载分压、LED 限流、时间常数、I²R、555 频率、反相运放、电容储能、分流 9 类题型，并加入 ≥60V/≥10A 数值风险门禁与多电源域诚实降级。门禁测试保证通过率不回退。详见 [docs/AGENT-EVAL.md](docs/AGENT-EVAL.md)。
- 智能体 RAG 检索（0.9.0）：本地知识检索升级为“多路召回 + RRF 融合”——原始查询、约 100 组领域同义扩展与 15 条主题专项路由并行召回，按权威层级、bm25 与整词命中融合排序，再逐源限流。检索强度分标准/深度/穷尽三档，可在知识中枢与设置页切换；知识中枢展示“检索过程”面板（每条路线的词元、命中数与耗时），方案页与 Agent 轨迹同步显示多路召回细节。
- AI 接口更聪明（0.9.0）：系统提示词重写为电路工程审阅协议（拓扑匹配 → 证据分级 → 最坏工况 → 安全门禁），注入九大电路族的领域审查指南；知识片段注入量与长度提升，要求模型按标题/页码引用并在资料冲突时优先权威层级；新增推理温度、Ollama 上下文窗口与注入条数设置；知识片段默认只发送到本机环回接口，发给远程模型需显式开启开关。

- 电路工作室（0.9.1 大更新）：61 类常用元件可拖放，也可点击添加到无限网格画布，覆盖无源器件（电阻/电位器/热敏/压敏/光敏/磁珠、电容/电解/钽、电感/晶振/变压器）、半导体（二极管/肖特基/齐纳/TVS/光敏、LED、BJT、N/P-MOSFET、SCR/TRIAC/IGBT、光耦）、模拟与集成（运放/比较器/稳压器/逻辑门/555）、电源与接口（电源/电池/电池座/地、连接器/排针/跳线/USB/DC 座、开关/按键/拨码、天线、保险丝/测试点）、执行器（继电器/直流电机/步进/舵机/风扇/电磁铁/蜂鸣器/扬声器/麦克风）与功能模块（红外接收/三线与 I2C 传感器/超声波/显示屏/无线模组/MCU）。新增“市场元件”页签：50 件常用真实器件预设（STM32F103C8T6、AMS1117-3.3、TB6612FNG、HC-SR04、ESP32 模组等），带封装徽标、分组筛选与型号/用途搜索，点击或拖入即放置为带型号的元件。可用平移工具、空格 + 左键、鼠标中键或滚轮移动视角，`Ctrl + 滚轮`围绕指针缩放。元件坐标不再受 `1000 × 680` 边界限制，项目会保存当前视角，SVG 导出自动覆盖全部内容。每个真实引脚末端常显独立绿色标记点，线头靠近端点会自动吸附、补齐最后一个正交转角并精确绑定引脚；只允许连接两个不同元件，多引脚元件可逐引脚独立布线。新线与旧线相交或重叠时会逐点询问“连接”或“仅跨线”。1120 px 窄屏下属性面板默认收起，展开后点击画布即可关闭。
- 连续布线校验：生成器逐端点检查所有内置原理图模板，拒绝悬空端点、无效线段和关键引脚断开；工作室实时显示连通状态，元件移动或旋转后导线仍绑定原引脚。
- 原理图符号物品栏：元件卡片直接显示电阻、电容、电感、二极管、LED、MOSFET、开关、保险丝、电源和接地等标准电路图符号，不再使用字母方块作为主图标。
- 图纸与项目导出：可导出 SVG 矢量电路图纸及 `.circuit.json` 可编辑项目。
- 自然语言需求解析：识别电压、电流、频率、增益、控制电平、电机数量与堵转电流；内置 Buck、Boost、LDO、运放、555、整流、MOSFET 驱动、双电机 H 桥、LED、MCU 供电、RC 滤波等模板。
- 可实现参考首版：将“点亮灯泡”等简短表达映射为低压安全方案，补齐输入接口、保护、开关、限流、负载、地、具体数值、封装建议和逐条网络连接，不再用通用方框图冒充电路。
- 小车动力方案：把“驱动小车”识别为双路 H 桥，生成动力入口保险/反接/TVS、储能与去耦、MCU 控制、左右电机连接、堵转门禁、热/EMI 校核和实测计划，不再退化成通用方框图。
- 连续修改：在当前方案下继续输入“改为 12V”“堵转电流 2.5A”“换白色 LED”“去掉开关”等要求，系统继承上一版并重新计算元件、BOM 和工程校验报告。
- 题目助手：本地公式求解串/并联电阻、分压、RC 截止频率、运放增益、欧姆定律和功率，并显示已知量、公式、步骤与适用边界。
- 电路优化：从连接、参考地、重复位号、退耦、保护以及噪声、功耗、成本、尺寸、可靠性目标生成分级检查报告。
- 知识增强：基础与进阶知识已真正进入生成链路；新增 Buck/Boost 最坏工况、运放/ADC、电机 H 桥、TVS、IPC-2152 载流、LDO 热门禁、LED 恒流、整流浪涌、MCU 电源域、反接与倒灌、接口分级防护、地平面策略、电源分配网络、PWM 频率、继电器应力与锂电池安全边界等规则，公开来源清单扩展到 28 条（含 MIT OpenCourseWare 与 TI/ADI/Infineon/Microchip/Keysight/NXP 官方资料），并为新增条目记录权威层级、交叉比对和适用边界；输出会列出命中的公开来源。
- 工程校验：检查关键参数门禁、拓扑矛盾、保护/去耦、专项额定值、布局验证闭环和高风险关键词；缺少堵转电流等必要输入时只给参数化草案。
- 图片识别：无模型时执行低置信度像素结构分析；接入视觉模型时分析功能、模块、器件、依据和不确定项。
- AI 接口：内置规则核心、Ollama 本地模型、OpenAI 兼容接口。

## 直接运行

本次准确性修复验证版请双击 `artifacts/accuracy-optimization-2026-10-16/build/win-unpacked/电路助手 Studio.exe`，并保留整个 `win-unpacked` 目录；也可执行 `npm.cmd start` 运行当前源码。

原 0.9.1 发布文件位于 `release-0.9.1/win-unpacked/电路助手 Studio.exe`；`release-0.9.1/电路助手-0.9.1-x64.exe` 是对应的单文件 Windows x64 便携版（需先执行 `npm.cmd run verify:release` 重新生成；0.8.7 的旧便携包仍在 `release-0.8.7/`）。

## 启动开发版

```powershell
npm.cmd install
npm.cmd start
```

完整本地验收会运行单元测试和隔离 Electron 界面流程，不读取日常用户数据：

```powershell
npm.cmd run verify
```

## 生成 Windows 便携版

```powershell
npm.cmd run verify:release
```

输出位于 `release-0.9.1/`（以 package.json 的 build.directories.output 为准）。便携版不需要安装，但体积包含 Electron 运行时。发布验证会先运行单元测试，构建后再从 `win-unpacked` 执行隔离 Electron smoke。

## 配置完全离线的视觉 AI

1. 在本机安装 Ollama。
2. 由用户明确下载一个支持视觉输入的模型，例如 `ollama pull gemma3:4b`。模型通常较大，本软件不会静默下载。
3. 启动 Ollama 后，在软件“AI 与设置”选择“Ollama 本地模型”。
4. 服务地址保持 `http://127.0.0.1:11434`，模型名与本机已安装模型一致。

模型下载完成后，推理过程可断开互联网运行；图片只提交给本机环回服务。没有模型时，软件仍可使用参数化生成、知识检索、工程校验和基础结构识图功能。

## 重要边界

本软件当前输出是“概念级/参数化草案”，不是可直接生产的设计。进入 PCB 前必须绑定真实器件符号、引脚和封装，并完成数据手册核对、ERC/DRC、SPICE/厂商模型仿真、热分析、样机测试与专业安全评审。市电、高压、锂电和大电流设计会被工程校验标记为阻断投板。

详细设计见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，AI 接口见 [docs/AI-INTEGRATION.md](docs/AI-INTEGRATION.md)。视觉验收图位于 `artifacts/`。

本地书籍知识库使用 SQLite FTS5，并支持从用户合法持有的 PDF、Markdown、TXT、JSON 资料导入；不会自动联网抓取或附带出版社书籍正文。配置、表结构和 SQL 示例见 [docs/LOCAL-KNOWLEDGE-SQL.md](docs/LOCAL-KNOWLEDGE-SQL.md)。
