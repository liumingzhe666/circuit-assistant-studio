# 0.8.7 Agent 恢复与发布闭环

## 目标

把上一版仅存在于内存的 Agent 运行记录升级为可恢复的本机工作记录，压缩工作台首屏，并交付经过单元、Electron 与打包后验证的 0.8.7 便携版。

## 验收关键结果

- KR1：最近 8 次运行跨重启保留；每次方案或优化报告使用独立快照，旧记录不会误开最新结果。
- KR2：异常关闭时的运行中任务恢复为明确的中断状态，不自动重放模型或伪装完成。
- KR3：Agent 工作台在 1120 x 720 最小窗口无横向溢出，首屏可看到任务、执行与历史入口；工作室窄屏属性面板不默认遮挡画布。
- KR4：单元测试、源码 Electron smoke、打包后 smoke 全部通过，并生成独立 0.8.7 目录、发布说明与 SHA-256。

## 范围

- 保留 Electron、原生 JavaScript/CSS、SQLite 与现有确定性电路核心。
- 不连接真实外部模型，不增加 SPICE/KiCad 能力，不覆盖历史 `release-0.8.6`。
- 会话文件限制体积和结构，损坏文件原样保留并停止覆盖。
