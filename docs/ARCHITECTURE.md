# 电路助手架构

## 核心原则

软件采用“离线可用、模型可换、结果可审查”的结构。通用大模型不是唯一核心：即使没有模型，本地专业核心也能解析需求、检索可追溯资料、生成拓扑草案、计算基础参数，并执行独立工程校验。

```text
需求 / 图片 / 工作室项目 / 电路题目
    │
    ├─ 交互式工作室 ── 元件物品栏、连线、属性、项目存储、SVG 导出
    │
    ├─ 意图与公式解析器 ── 参数、拓扑候选、可复核求解步骤
    │          └──── 模糊需求安全默认值 + 完整参考首版 + 版本化修改
    │
    ├─ 知识检索 ── 基础知识 → 结构化进阶规则 → 用户导入资料（可追溯）
    │
    ├─ 电路专业核心 ── 模板、公式、连接和布局规则
    │          └──── 可选 Ollama / OpenAI 兼容模型增强
    │
    ├─ 优化检查 ── 连接、噪声、功耗、成本、尺寸、可靠性
    │
    └─ 工程校验 ── 参数门禁、完整性、矛盾、安全、验证闭环与置信边界
               │
               └─ 工作室 SVG / 项目 JSON / 原理图 SVG / BOM / PCB 交接 JSON
```

## 进程与安全

- Electron 渲染进程启用 `contextIsolation`、`sandbox`，关闭 `nodeIntegration`。
- 页面使用自定义 `circuit://` 协议加载本地资源，并配置严格 CSP。
- 渲染进程只能通过细粒度 IPC 调用保存、知识导入和 AI 服务。
- 远程接口只允许 HTTPS；HTTP 只允许 `localhost`、`127.0.0.1` 或 `::1`。
- API Key 通过 Electron `safeStorage` 调用 Windows 系统加密能力后保存。
- Agent 会话通过受限 IPC 写入用户数据目录的 `agent-session.json`；文件和输入上限为 2 MiB，最近保留 8 次运行，每次最多 32 个步骤。非法、损坏或超限文件会原样保留并拒绝覆盖。

## 后台模块职责

### Agent 运行与恢复

- 渲染进程只记录可观察的工具阶段、状态和结果摘要，不保存或展示模型隐藏推理。
- 每次方案生成和优化审查保存独立 JSON 结果快照；选择旧记录时重新渲染该快照，避免打开当前最新结果。
- 运行开始、阶段变化和结束都会排队持久化。应用重启后，遗留的 `running` 记录转换为明确的中断失败：运行中步骤标记失败，未开始步骤标记跳过，不自动重新发送模型请求。
- 主进程使用与项目/设置相同的单进程 FIFO 修改队列和原子替换；当前仍不提供跨进程文件锁或断电恢复保证。

### 参考首版生成器

- 优先从已验证模板选择能够实现需求的低风险电路，不再对已识别功能输出通用方框图。
- 同时生成可绘制符号、BOM、位号、建议值、封装、网络连接、计算依据和明确假设。
- 用户修改基于当前版本重算，保留修订编号与修改记录；电压、电流、颜色和开关状态会同步更新到图纸及 BOM。
- 无法安全识别功能时仍会要求补充信息，不以虚构器件填补未知条件。

### 知识检索与规则应用

- 检索 `knowledge/basic-circuits.json` 与 `knowledge/advanced-circuits.json` 中的分层理论与来源。
- 用户合法持有的 PDF/Markdown/TXT/JSON 资料写入本机 SQLite；`library_sources` 保存来源与权利审计，`knowledge_chunks` 保存分页文本块，`knowledge_fts` 提供中文双字增强的 FTS5 检索。
- 需求生成和连续修订会召回最多 8 个本地片段；只有实际服务地址为回环地址的 Ollama 或兼容模型才能接收自动附加的片段，远程 Ollama 同样排除正文；请求禁止重定向。此限制不等于对需求文本或方案元数据的全面脱敏。
- 进阶层覆盖等效网络、瞬态、RLC、稳定性、有源滤波、ADC 驱动、电源环路、EMI、高速/RF 布局、热设计、SPICE 和 KiCad ERC/DRC 流程；结构化规则会进入生成结果的校核与验证清单。
- 用户导入资料默认 `verified=false`，不会自动提升为权威规则；它会作为本机模型的可追溯参考，但不能覆盖确定性计算。

### 工程校验

- 方案生成完成后独立执行，不复用“已通过”的假设。
- 检查拓扑方向、关键规格、网络/BOM 完整性、PCB 建议和验证闭环。
- 高压、市电、锂电与大电流关键词会触发“阻断投板”。
- 分数只是审查覆盖度，不是电路可靠性概率。
