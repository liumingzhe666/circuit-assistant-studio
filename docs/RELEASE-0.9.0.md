# 发布说明 · 0.9.0

本版本围绕“让智能体更聪明”扩展了检索、推理与知识三条链路，并同步升级界面。

## 智能体 RAG 检索强度

- 检索从单路 FTS5 升级为**多路召回 + RRF 融合**：原始查询、领域同义扩展（约 100 组口语↔术语映射）与主题专项路由（15 条，覆盖 Buck/Boost/LDO/电机驱动/LED/运放/ADC/MCU/PCB 载流/浪涌保护/热设计/EMI/电池安全/555/滤波）并行召回。
- 新增**检索强度三档**：标准 / 深度（默认）/ 穷尽，控制候选池、返回条数、逐源上限与主题路由开关；设置页与知识中枢均可切换，全局生效。
- 新增**检索过程追踪**：每条路线的词元与命中数、同义扩展清单、候选/选出数量与耗时。知识中枢显示“检索过程”面板，方案页“可追溯工程依据”显示检索摘要，Agent 执行轨迹显示多路召回细节。
- 融合排序叠加权威层级（A+/A）、bm25 归一化分与整词命中奖励；逐源限流防止单一文档垄断上下文。

## AI 接口更聪明

- 系统提示词重写为**电路工程审阅协议**：意图与拓扑匹配 → 证据分级（数据手册 > 厂商应用笔记/标准 > 教科书公式 > 假设）→ 最坏工况清单 → 安全门禁 → unknown 纪律。
- 新增**领域审查指南**注入：开关电源、LDO、电机/H桥、LED、模拟、MCU、接口、PCB、安全九大族的必查项。
- **RAG 上下文注入增强**：默认注入条数 8 → 12，单条截断 1400 → 2000 字符；片段带权威层级与页码；要求模型在 `knowledgeCitations` 中引用并在资料冲突时优先权威层级。
- 题目助手也会把相关知识片段交给模型，讲解需说明公式来源与适用边界。
- 新增推理参数：温度（默认 0.15）、Ollama 上下文窗口（默认 8192）、注入条数（6–20）。
- **远程知识开关（默认关闭）**：知识片段默认只发送到本机环回接口；如需发给远程模型必须在设置中显式开启，保留隐私边界。

## 知识库扩充

- 基础知识 14 → 25 条：新增二极管选型差异、电容直流偏压、上拉/下拉、去耦摆放、分压采样、接口 ESD、晶振负载电容、复位监控、继电器/蜂鸣器驱动、参考地与回流、LED 限流与恒流。
- 进阶知识 26 → 39 条（其中带 `rules` 可进入生成链路 20 条）：新增 LDO 热门禁、LED 恒流、555 精度、整流浪涌、MCU 电源域、单电源运放偏置、反接与倒灌、接口分级防护、地平面策略、电源分配网络、PWM 频率权衡、继电器应力、锂电池安全边界。
- 内存检索（内置条目）与 SQLite 检索同步接入同义扩展，两条链路行为一致。

## 界面扩充

- 知识中枢：检索强度切换胶囊、检索过程追踪面板、SQL 命中片段的融合路数徽标。
- 设置页新增“知识检索与上下文”卡片：检索强度、注入条数、温度、上下文窗口与远程知识开关。
- 智能生成与 Agent 工作台：知识阶段显示“N 路召回 · 候选 M 片段”，方案页显示检索摘要。

## 验证

- `npm run test:ui`：隔离 Electron 界面流程通过，证据位于 `artifacts/ui-smoke-0.9.0/`。
