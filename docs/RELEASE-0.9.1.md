# 发布说明 · 0.9.1

本版本聚焦电路工作室（原理图画板）：扩充元件与市场器件库、修复交互缺陷、美化物品栏与属性面板。

## 元件库扩充（34 → 61 种符号）

- 无源器件新增：热敏电阻（NTC）、压敏电阻、光敏电阻、磁珠、钽电容。
- 半导体新增：TVS 二极管、光敏二极管、单向可控硅（SCR）、双向可控硅（TRIAC）、IGBT。
- 电源与接口新增：按键开关、拨码开关、USB 接口、DC 电源座、排针、跳线、电池座、天线。
- 执行器新增：步进电机、舵机、风扇、电磁铁、扬声器、驻极体麦克风。
- 功能模块新增：红外接收头、三引脚传感器、I2C 传感器、超声波模块、显示屏、无线模块。
- 每种新类型都带专属 SVG 符号、真实引脚定义、自动布线碰撞区与选中框。

## 市场元件库（仿嘉立创器件面板）

- 新增“市场元件”页签：**50 件常用真实器件**预设，覆盖主控与逻辑（STM32F103C8T6、ATmega328P、ESP32-WROOM-32E、CH340G、74HC595、NE555）、电源管理（AMS1117-3.3、LM2596、MP1584、MT3608、TP4056）、电机与功率（L298N、TB6612FNG、DRV8833、A4988、ULN2003、BTA16、SMAJ5.0A）、传感器（DHT11、DS18B20、HC-SR04、MPU6050、BMP280 等）、无线与通信（HC-05、NRF24L01+、LoRa、MAX485、Neo-6M）、显示与交互（LCD1602、0.96" OLED、TM1637、SG90）、存储与接口（W25Q64、AT24C02、PC817、74LVC245）、常用基础件（0603 10kΩ、100nF、钽电容、晶振、NTC、压敏、磁珠、按键、DC-005、USB 座等）。
- 卡片显示型号、用途、封装徽标；支持型号/名称/封装/用途搜索与 8 个分组筛选；点击放置到画布中央或直接拖到指定位置。
- 放置的元件自带型号、封装建议与工程说明；价格与库存以立创商城等供应商实时信息为准。

## 画板修复与体验

- 修复：**密集引脚连线接错引脚**（E2E 发现的严重 bug）——命中圈半径 14px 大于新元件 12px 引脚间距，相邻引脚的透明命中圈会盖住点击点，点击 P1 却连到 P2。现在命中圈短路前会验证引脚中心确实贴近点击点（≤7px），否则按画布距离精确取最近引脚。
- 修复：**三引脚/I2C 传感器符号引脚线的 SVG 路径数字粘连**（如 `M-280`），引脚线渲染破损。
- 修复：排针的碰撞体矩形覆盖到引脚位置，导致到达引脚的导线被误判穿体而触发绕线。
- 修复：**无限画布回归演示失效**——0.8.7 默认页改为 Agent 工作台后，该演示未切换到工作室页面，画布 `display:none` 导致全部坐标为 0；现已修复并加大拖动/平移位移，使其在窄屏与宽屏窗口下都稳定通过。
- 修复：工具切换时 `className` 整体覆盖会清掉拖拽/平移状态类的问题，改为仅切换工具类。
- 修复：撤销/重做、新建或打开项目后，未答复的导线交点询问会残留弹窗的问题；交点答复现在也纳入撤销历史。
- 修复：拖动元件时，导线结点/跨线标记滞后于旧位置的问题，现在实时跟随（无交点时零开销）。
- 修复：物品栏搜索后市场元件卡片可能被绑定错误点击事件的问题（事件绑定限定各自页签作用域）。
- 优化：非连线模式下引脚标记点弱化显示且不再拦截点击，画面更干净，也避免选择元件时误触引脚。
- 改进：`--*-demo` 回归参数单独运行时自动进入截图模式并正常退出（默认输出 `artifacts/last-demo.png`），不再挂起；回归失败与渲染进程异常会同步写入临时目录 `circuit-assistant-demo-error.log`，非 TTY 环境也能排查。
- 物品栏美化：更大的符号预览卡片、悬停浮起反馈、搜索无结果引导；搜索框同时支持元件与市场型号。
- 属性面板新增常用值快填芯片（电阻/电容/电感/晶振等一键填值）。
- 新增 `--place=`、`--market-demo` 与 `--studio-e2e-demo` 演示参数，便于回归验证。
